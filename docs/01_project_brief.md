# Project brief: Aviasales flight-price analytics

## Контекст

Путешественники выбирают даты, направления и маршруты в условиях изменяющихся цен.
Цель проекта — исследовать доступные данные о минимальных ценах на авиабилеты и выявить факторы, связанные с более выгодными вариантами перелёта.

## Основной вопрос

Как связаны минимальная цена авиабилета, направление, дата вылета, длительность поездки, количество пересадок и время до вылета?

## Цель

Создать воспроизводимый пайплайн, который получает данные из Aviasales Data API,
сохраняет исходный ответ, подготавливает аналитическую таблицу и строит визуализации
для исследования цен по выбранным направлениям.

## Источник данных

Aviasales Data API / Travelpayouts.

Данные представляют кэшированные цены, обнаруженные в поисках пользователей.
Они не являются полным набором бронирований или продаж и могут быть актуальны
лишь в рамках периода хранения API.

## Единица наблюдения

Одно ценовое предложение для заданного маршрута и параметров поездки,
полученное из API на конкретную дату сбора.

## Первичные метрики

- Минимальная цена билета
- Медианная цена по направлению
- Количество доступных предложений
- Доля прямых перелётов
- Медианная продолжительность перелёта
- Разница в цене прямых рейсов и рейсов с пересадками

## Разрезы анализа

- Маршрут: аэропорт отправления → аэропорт назначения
- Дата вылета
- Месяц и день недели вылета
- Время до вылета на момент сбора
- Количество пересадок
- Авиакомпания
- Продолжительность перелёта
- Тип поездки: в одну сторону или туда-обратно

## Ограничения

- API возвращает данные из кэша, а не полный поток продаж.
- Набор цен меняется со временем, поэтому важно сохранять дату и время выгрузки.
- Результаты нельзя интерпретировать как причинный эффект без дополнительной проверки.
- Для воспроизводимости в репозиторий не добавляются токены и реальные сырые данные.

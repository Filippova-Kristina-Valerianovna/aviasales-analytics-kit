# Data dictionary: flight prices

## Набор данных

Локальный файл:

```text
data/processed/flight_prices_2026-11.csv
```

Содержит 150 ценовых наблюдений, собранных через Aviasales Data API / Travelpayouts
для пяти внутренних маршрутов России. Выгрузка была выполнена 2 октября 2026 года,
а рассматриваемый месяц вылета — ноябрь 2026 года.

Данные не хранятся в GitHub: они создаются локально скриптами из `src/`.

## Единица наблюдения

Одна запись API о доступном ценовом предложении для заданного маршрута,
даты и параметров перелёта.

## Поля

| Поле | Тип | Описание |
|---|---|---|
| `route` | text | Маршрут в формате `origin → destination` |
| `origin` | text | IATA-код города отправления |
| `destination` | text | IATA-код города назначения |
| `departure_at` | datetime | Дата и время вылета |
| `departure_date` | date | Календарная дата вылета |
| `departure_weekday` | text | День недели вылета |
| `departure_hour` | integer | Час вылета |
| `return_at` | datetime | Дата и время обратного вылета; пусто для поездок в одну сторону |
| `price` | integer | Минимальная цена в рублях в кэшированном API-наблюдении |
| `airline` | text | IATA-код авиакомпании |
| `transfers` | integer | Количество пересадок |
| `is_direct` | boolean | `True`, если перелёт прямой |
| `duration` | integer | Продолжительность перелёта в минутах |
| `duration_hours` | float | Продолжительность перелёта в часах |
| `found_at` | datetime | Время, когда API зафиксировал предложение |
| `collected_at_utc` | datetime | Время выгрузки из API в UTC |
| `days_before_departure` | integer | Сколько календарных дней оставалось до вылета в момент выгрузки |
| `requested_departure_month` | text | Месяц, переданный в API-запросе |
| `source_file` | text | Имя исходного JSON-файла из `data/raw/` |

## Проверки качества

На первой выгрузке:

- 150 строк;
- 5 маршрутов;
- 30 строк на каждый маршрут;
- диапазон дат вылета: 1–30 ноября 2026 года;
- диапазон цен: 3 133–9 120 ₽;
- пропусков в цене: 0;
- полных дубликатов: 0.

## Ограничения данных

- Цены поступают из кэша Aviasales Data API / Travelpayouts и могут изменяться со временем.
- Это не полный набор бронирований, продаж или поисковых сессий пользователей.
- Набор охватывает только пять выбранных внутренних маршрутов и один месяц вылета.
- Ответы API могут быть отсортированы по цене, поэтому этот набор не следует интерпретировать как случайную выборку всех доступных билетов.
- Выводы относятся к наблюдениям, доступным на момент выгрузки.

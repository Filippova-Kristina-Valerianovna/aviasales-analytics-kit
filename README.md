# Aviasales Analytics Kit

Учебный аналитический проект для исследования данных о перелётах и ценах на авиабилеты.

## Цель проекта

Построить воспроизводимый аналитический пайплайн, который поможет:

- загружать и хранить исходные данные о рейсах и авиабилетах;
- очищать и подготавливать данные для анализа;
- исследовать цены, направления, авиакомпании и сезонность;
- формировать аналитические отчёты и визуализации;
- развивать дашборд, dbt-трансформации и интерфейс бота.

## Структура проекта

```text
aviasales-analytics-kit/
```

## Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Filippova-Kristina-Valerianovna/aviasales-analytics-kit.git
   ```

2. Создайте и активируйте Conda-окружение:

   ```bash
   conda create -n aviasales-analytics python=3.13 -y
   conda activate aviasales-analytics
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите проверочный ноутбук:

   ```text
   notebooks/01_environment_check.ipynb
   ```

## Выполненное исследование: EDA цен на авиабилеты

Первое завершённое исследование проекта — разведочный анализ цен на авиабилеты на основе данных Travelpayouts / Aviasales Data API.

**Ноутбук:** [`notebooks/02_flight_prices_eda.ipynb`](notebooks/02_flight_prices_eda.ipynb)

### Цель исследования

Понять, как цена авиабилета связана с маршрутом, количеством пересадок и горизонтом бронирования — числом дней между датой сбора данных и датой вылета.

### Данные

- Источник: Travelpayouts / Aviasales Data API
- Дата сбора: 3 октября 2026 года
- Размер выборки: 305 предложений
- Маршруты: 41
- Период вылета: 9 октября 2026 — 31 января 2027 года
- Валюта: RUB

API предоставляет кэшированные цены, сформированные на основе истории поисковых запросов пользователей. Поэтому данные не отражают фактические продажи или подтверждённые бронирования и не должны интерпретироваться как актуальные рыночные цены. [Travelpayouts Data API](https://support.travelpayouts.com/hc/en-us/articles/203956163-Aviasales-Data-API) указывает, что информация передаётся из кэша поисковой истории; кэш может хранить данные до 7 дней. [255]

### Основные результаты

- Цена в выборке находится в диапазоне от **4 480 ₽** до **43 772 ₽**; медиана — **14 593 ₽**, среднее — **15 155 ₽**.
- Маршруты заметно различаются по уровню цен: самая низкая медианная цена в выборке у `MOW -> LED` — **5 442 ₽** при 7 предложениях; самая высокая у `SVX -> TJM` — **28 412 ₽** при 4 предложениях.
- Прямые рейсы составляют **83,0%** выборки: их медианная цена — **13 776 ₽**, медианная длительность — **6,25 часа**.
- Для вариантов с одной пересадкой медианная цена составляет **18 686 ₽**, а медианная длительность — **32,92 часа**. Это описательное наблюдение по данной выборке, а не доказательство причинного влияния пересадки на цену.
- Для интерпретации горизонта бронирования 15 исходных значений `days_before_departure` объединены в 8 когорт: 7, 14, 21, 30, 45, 60, 90 и 120 дней.
- Самая высокая медианная цена в доступной выборке наблюдается в когорте **90 дней до вылета** — **19 640 ₽**. Этот результат нужно интерпретировать осторожно из-за разового сбора, неполного покрытия комбинаций «маршрут × дата» и кэшированного характера API‑данных.

### Как запустить EDA

После установки зависимостей из раздела «Быстрый старт» открой и выполни ячейки по порядку:

```text
notebooks/02_flight_prices_eda.ipynb
```

### Ограничения и следующий этап

- Данные собраны за один день, поэтому они не позволяют оценить изменение цены во времени для одинаковых маршрутов и дат вылета.
- Не все комбинации «маршрут × дата вылета» вернули предложение.
- Наблюдаемые взаимосвязи не доказывают причинно-следственную связь.
- Следующий этап: автоматизировать регулярный сбор, накопить временной ряд цен и исследовать динамику стоимости по мере приближения даты вылета.
